# UsersWebAPI

This is a .NET 8 Web API sample with:
- Users model (Name, Age, City, State, Pincode)
- CRUD endpoints (GET, GET by id, POST, PUT, DELETE)
- JWT authentication (use POST /api/auth/login with username=test & password=test)
- EF Core with SQLite (DB file at /data/app.db)
- Swagger enabled
- NUnit integration test for DELETE
